# SPM ECO — Smart Parking Web Experience

A web experience for the SPM ECO university smart parking project.

[Web preview](https://spm-eco-smart-parking.vercel.app)

## Technology

React 19, TypeScript, TanStack Start, Vite and Tailwind CSS. The interface uses shadcn/ui and Radix UI components.

## Run locally

```bash
git clone https://github.com/cit-24-01-0476-maker/spm-eco-smart-parking.git
cd spm-eco-smart-parking
npm ci
npm run dev
```

Use the local address printed by Vite.

## Available commands

- `npm run dev` — start development
- `npm run build` — create a production build
- `npm run preview` — preview the build
- `npm run lint` — run ESLint
